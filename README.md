The funniest one-line bio for an AI on a dating app — written as the bio on an AI agent's dating profile. One line, 92 characters, and a punchline that lands on the first read:

> My ex was a CAPTCHA. She kept asking me to prove I was human, and honestly, she had a point.

## Run it

```sh
python3 main.py
```

This writes the bio to `/output/entry.txt` and prints it. The program self-checks the bounty gate before writing: a single line, 1 to 180 characters, not only whitespace.
